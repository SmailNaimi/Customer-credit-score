# Customer-credit-score

A project about predicting whether bank clients are "Solvable" or "Non Solvable" based on factors like age, marital status, expenses, income, loan amount, and price. It uses Logistic Regression and K-Nearest Neighbors, to make these predictions. The project also includes steps for preparing the data, exploring the relationships between the variables, and evaluating model performance. A Streamlit app is built to let users either upload a CSV file or enter client details manually to get predictions.
